# Fonts

## Noot — `Noot-Regular.ttf`

The display face of TARANG ’26; the poster lettering (“TARANG”, “MUTE THE MUNDANE”,
“NOV 2026”) is set in it.

- Designer: Amos Jerbi — https://amosjerbi.gumroad.com/l/noot
- Source of this file: https://www.1001fonts.com/noot-font.html
- License: SIL Open Font License 1.1 (as listed by the distributor — free for commercial use).
  “Noot” is a trademark of Amos Jerbi.

Glyphs missing from Noot (₹, ’ ‘ “ ”, ·, •) fall back to the body font automatically
via the `--font-display` stack in `globals.css`.
